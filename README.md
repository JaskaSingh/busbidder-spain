# BusBidder Spain

A command-line application that filters and ranks bus offers from five
simulated companies according to an individual traveller's requirements
and preferences. Final project for ACIT4420 Problem Solving with Scripting,
OsloMet, autumn 2026.

## Requirements

Python 3.12. Standard library only.

## Running

From the repository root:

    python3 -m busbidder

## Tests

From the repository root:

    python3 -m unittest
